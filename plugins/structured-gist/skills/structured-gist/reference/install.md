# Install

Install nested-notes from the Claude Code marketplace:

```
claude plugin install nested-notes@claude-ai
```

After installation, invoke the skill with:

```
/nested-notes [level] [mode]
```

Where:
- `level`: one of `skim` (default), `standard`, `deep`
- `mode`: one of `block` (default), `inline`, `responsive`

See `SKILL.md` for the complete rule set and render-mode details.
