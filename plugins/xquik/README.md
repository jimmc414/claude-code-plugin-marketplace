# xquik

Xquik workflows for X data automation with MCP, REST APIs, webhooks, extraction, monitoring, and confirmation-gated writes.

## Installation

```bash
/plugin marketplace add jimmc414/claude-code-plugin-marketplace
/plugin install xquik@community-claude-plugins
```

## Components

| Type | Name | Description |
|------|------|-------------|
| **Skill** | `xquik-x-data` | Configure Xquik MCP and REST workflows from public docs |

## Usage

Use this plugin when you need to:

- Connect the public Xquik MCP server
- Read endpoint-specific REST API contracts
- Plan extraction and monitoring workflows
- Configure webhooks
- Prepare write actions that keep explicit confirmation steps
